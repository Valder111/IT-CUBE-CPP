# Практика по темам "Динамическая память" и "Структуры" в С++

### Задание 1. «Каталог книг» 

**Ситуация:**  
Вы разрабатываете консольную программу для школьной библиотеки. Библиотекарь не знает заранее, сколько книг нужно внести, так как это зависит от дня.

**Требования:**
1. Объявите структуру `Book` с полями:
   - `std::string title` (название_книги)
   - `std::string author` (автор_книги)
   - `int year` (год_издания_книги)
2. Программа запрашивает у пользователя **количество книг**.
3. Выделяет **динамический массив** структур `Book` нужного размера.
4. Позволяет ввести данные по каждой книге.
5. Выводит весь каталог.
6. **Корректно освобождает память.**

### Задание 2. «Учёт сотрудников» 

**Ситуация:**  
HR-отдел небольшой компании хочет вести список новых сотрудников, но не использует базы данных — только временный консольный учёт при приёме на работу.

**Требования:**
1. Объявите структуру `Employee`:
   - `std::string name` (имя_кандидата)
   - `int id` (id_кандидата)
   - `double salary` (зарплата)
2. Программа работает в цикле:
   - Сначала спрашивает: «Сколько сотрудников добавить?»
   - Выделяет **динамический массив** из `n` структур.
   - Заполняет данные.
   - Выводит список.
   - **Освобождает память.**
3. Добавьте **защиту от ошибок**:
   - Если введено `n <= 0`, программа завершается корректно (без `new`).
   - После `delete[]` обнуляйте указатель.

### Решение задачи №1. ВНИМАТЕЛЬНО ознакомьтесь с ним. По возможности, запустите его у себя на компьютере/ноутбуке. Поредактируйте его, поизучайте и т.д. :

```cpp
#include <iostream>
#include <string>

using namespace std;

struct Book {
    string title;
    string author;
    int year;
};

int main() {
    setlocale(LC_ALL, "Rus");

    int n;
    cout << "Сколько книг вы хотите добавить? ";
    cin >> n;

    if (n <= 0) {
        cout << "Некорректное количество.\n";
        return 1;
    }

    // Выделяем динамический массив структур
    Book* catalog = new Book[n];

    // Ввод данных
    for (int i = 0; i < n; ++i) {
        cout << "\nКнига #" << (i + 1) << ":\n";
        cin.ignore(); // очистка буфера после cin >> n
        cout << "Название: ";
        getline(cin, catalog[i].title);
        cout << "Автор: ";
        getline(cin, catalog[i].author);
        cout << "Год издания: ";
        cin >> catalog[i].year;
    }

    // Вывод каталога
    cout << "\n--- Каталог книг ---\n";
    for (int i = 0; i < n; ++i) {
        cout << (i + 1) << ". " << catalog[i].title
             << " — " << catalog[i].author
             << " (" << catalog[i].year << ")\n";
    }

    // Освобождение памяти
    delete[] catalog;
    catalog = nullptr; // для предотвращения ошибок, указываем "стандартное" значения указателя после его использования в нашей программе

    return 0;
}
```

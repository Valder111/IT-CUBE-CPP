## Структуры в C++ (`struct`)

**Структура** (`struct`) - это пользовательский тип данных, который позволяет объединять несколько переменных **разных типов** в одну логическую единицу. Это удобно для описания объектов реального мира, состоящих из нескольких характеристик.

### Объявление и использование

Объявление структуры начинается с ключевого слова `struct`, за которым следует имя структуры и список её **полей** (членов):

```cpp
struct Student {
    string name;
    int age;
    double average_score;
};
```

После этого можно создавать переменные этого типа:

```cpp
Student s1;                     
s1.name = "Иван";
s1.age = 16;
s1.average_score = 4.75;
```

Доступ к полям осуществляется через оператор **точка** (`.`).

### Инициализация

Можно инициализировать структуру при создании:

```cpp
Student s2 = {"Анна", 17, 4.9};
// или можно так в современных версиях С++:
Student s3{"Петр", 16, 4.2};
```

### Структуры и функции

Структуры можно передавать в функции и возвращать из них:

```cpp
void printStudent(const Student& s) {
     cout << s.name << ", " << s.age << " лет, средний балл: " << s.average_score << "\n";
}
```

Передача по **константной ссылке** (`const Student&`) предотвращает ненужное копирование и защищает данные от изменения.

### Вложенные структуры и массивы структур

Можно создавать массивы из структур:

```cpp
Student group[30];  // группа из 30 студентов
group[0].name = "Мария";
```

А также вкладывать одни структуры в другие:

```cpp
struct Date {
    int day, month, year;
};

struct Person {
    string name;
    Date birth_date;  // вложенная структура в другую структуру (да, так можно делать чуть ли не до бесконечности)
};
```

### Отличие от `class`

*Мы ещё не проходили `class` и его свойства. Однако я оставлю этот блок на будущее, ну и для любознательных:*
В C++ `struct` и `class` очень похожи. Основное различие - **по умолчанию**:
- в `struct` все поля **публичные** (`public`); (доступны для обращения внутри и вне определяемой области в С++)
- в `class` - **приватные** (`private`). (недоступны за пределами класса)

Для простых, неложным типов данных (без сложной логики) обычно используют `struct`.

### Опасности и рекомендации

- Не стоит помещать в структуру слишком много полей - это усложняет код.
- Избегайте «голых» указателей внутри структур без чёткого управления памятью.
- Если структура содержит динамические данные (например, `char*`), потребуется явно определять конструкторы, деструктор и операторы присваивания. В таких случаях лучше использовать `std::string`, `std::vector` и т.п.

> **Совет:** Для хранения набора связанных данных (координаты точки, книга, сотрудник, фильм и т.д.) - структуры идеальны. Они делают ваш код понятнее и безопаснее.

### Пример грамотного использования

```cpp
#include <iostream>
#include <string>

struct Point {
    double x, y;
};

double distance(const Point& a, const Point& b) {
    double dx = a.x - b.x;
    double dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);   //извлекаем корень из выражения в скобках
}

int main() {
    Point p1{0.0, 0.0};
    Point p2{3.0, 4.0};
    
    cout << "Расстояние: " << distance(p1, p2) << endl; // выводит 5
    return 0;
}
```
